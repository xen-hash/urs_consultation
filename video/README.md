# URS teaser video

A 1:34 motion-graphics teaser for social media, built in code with
[Remotion](https://www.remotion.dev). Every animation is timed to the recorded
voiceover word by word, so replacing the narration re-times the whole video.

| | |
|---|---|
| Format | 1920×1080, 30 fps, H.264 MP4 |
| Script | `voiceover-script.md` |
| Narration | `public/voiceover.mp3` (ElevenLabs) |
| Word timings | `src/data/captions.json`, generated by `scripts/align.py` |

## Render it

```bash
cd video
npm install
npm run render            # → out/urs-teaser.mp4
npm run studio            # live preview with a timeline, in the browser
```

`remotion.config.js` points the render at the Chromium already installed in
Claude Code's cloud environment. On your own machine, run
`REMOTION_BROWSER= npm run render` instead, and Remotion will download its own
browser.

## Add the background music

1. Save the track as `public/music.mp3`.
2. In `src/Teaser.jsx`, set `export const MUSIC = "music.mp3";`.
3. Render again.

The music loops if it's shorter than the video. It automatically ducks under
the voice, comes up in the pauses and at the logo and end card, and fades out
over the last 2.5 seconds.

## Replace the narration

After regenerating the voiceover, or editing the script:

```bash
pip install pocketsphinx imageio-ffmpeg
cp new-voiceover.mp3 public/voiceover.mp3
python scripts/align.py   # re-times every word against the new audio
npm run render
```

Scenes find their moments by the words spoken ("one tap", "notification", and
so on) rather than by hard-coded seconds. A new recording therefore needs no
code changes, as long as the script's wording stays the same.

## Where things are

- `src/Teaser.jsx`: the scene order, captions and audio.
- `src/scenes/`: one component per scene:
  - `Opening.jsx`: cold open, hook, title
  - `Availability.jsx`: availability board, teacher status
  - `Booking.jsx`: booking, Navi
  - `Closing.jsx`: sign-in and install, kiosk and Dean's Office, end card
- `src/ui.jsx`: the mock app parts: browser window, phone, faculty card, status badge, pointer.
- `src/theme.js`: the app's colors, plus the faculty names shown on screen.
  These names are fictional; the real roster in `backend/config.py` is never shown.
- `scripts/stills.mjs 120 900`: renders single frames into `out/stills/` for a quick look.
